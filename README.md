## 📋 Daftar Fitur Lengkap / Complete Feature List

<details>
<summary><b>🏠 Dashboard</b></summary>

- Total saldo kas & bank real-time
- Grafik penerimaan vs pengeluaran (12 bulan)
- 5 transaksi terbaru
- Jumlah siswa aktif & tunggakan SPP
- Quick action buttons (+ Penerimaan, + Pengeluaran, Cetak Laporan)
- Summary kartu: Total Penerimaan Bulan Ini, Total Pengeluaran, Laba/Rugi

</details>

<details>
<summary><b>📚 Master Data</b></summary>

**Data Siswa:**
- NIS, Nama Lengkap, Kelas, Status (Aktif/Lulus/Keluar)
- Alamat, No. Telepon Orang Tua
- Riwayat transaksi SPP & Uang Gedung
- Import bulk dari Excel

**Kategori Akun (Chart of Accounts):**
- Kode Akun, Nama Akun, Tipe (Aktiva/Kewajiban/Ekuitas/Pendapatan/Biaya)
- Grup Akun, Saldo Normal (Debet/Kredit)
- Default 20+ akun standar sekolah sudah terisi

**Data Karyawan:**
- NIP, Nama, Jabatan (Guru Tetap/Honorer/TU/Kepsek/dll)
- Gaji Pokok, Tunjangan Tetap, No. Rekening
- Riwayat Gaji Bulanan

</details>

<details>
<summary><b>💰 Transaksi Penerimaan</b></summary>

**SPP:**
- Input per siswa per bulan
- Auto-hitung tunggakan
- Pilih metode bayar (Tunai/Transfer)
- No. Referensi untuk transfer
- Cetak kwitansi instant (PDF)
- Deteksi duplikasi pembayaran

**Uang Gedung & Uang Pangkal:**
- Total tagihan & sistem angsuran fleksibel
- Track sisa tagihan per siswa
- History angsuran lengkap

**Penerimaan Lain-lain:**
- Hibah, Sponsor, Donasi, Bunga Bank
- Hasil Penjualan Aset, Sewa Gedung
- Pilih akun akuntansi yang sesuai

</details>

<details>
<summary><b>💸 Transaksi Pengeluaran</b></summary>

**Pengeluaran Gaji:**
- Auto-kalkulasi dari data master karyawan
- Komponen: Gaji Pokok + Tunjangan Tetap + Tunjangan Variabel
- Potongan Otomatis: PPH 21, BPJS Kesehatan, BPJS Ketenagakerjaan, Pinjaman
- Cetak slip gaji karyawan
- Ekspor rekap gaji ke Excel

**Diskon:**
- Diskon SPP, Uang Gedung, Uang Pangkal
- Attach ke transaksi spesifik
- Catatan alasan diskon

**Pengadaan:**
- Vendor, Deskripsi Item, Nominal
- Attach ke akun biaya
- Upload faktur/nota (lampiran)

**Pengeluaran Rutin:**
- Listrik, Air, Telepon, ATK, Kebersihan, Keamanan, dll
- Pilih kategori & akun secara otomatis
- Recurring expense reminder

</details>

<details>
<summary><b>📊 Laporan Keuangan (7 Laporan)</b></summary>

1. **Laporan Penerimaan** — Ringkasan semua penerimaan by periode & kategori
2. **Laporan Pengeluaran** — Ringkasan semua pengeluaran by periode & kategori  
3. **Buku Besar** — General Ledger per akun dengan saldo berjalan
4. **Neraca Saldo** — Trial Balance debet vs kredit
5. **Laba/Rugi** — Profit & Loss Statement
6. **Neraca** — Balance Sheet (Aktiva = Kewajiban + Ekuitas)
7. **Arus Kas** — Cash Flow Statement (Operasi, Investasi, Pendanaan)

Semua laporan: filter by periode, export PDF & Excel

</details>

<details>
<summary><b>⚙️ Fitur Lainnya</b></summary>

- **Backup & Restore** — Backup manual atau otomatis terjadwal, restore 1 klik
- **Export PDF** — Layout profesional, siap print, header nama sekolah
- **Export Excel** — Format .xlsx dengan formula, siap untuk diolah lebih lanjut
- **Multi-User** — Admin dan Staff dengan level akses berbeda
- **Audit Log** — Riwayat semua perubahan data dengan timestamp
- **Pengaturan Sekolah** — Nama, alamat, logo, nomor SK sekolah
- **Ganti Password** — Sekuriti akun pengguna

</details>

## 🚀 Installation / Instalasi

### 🖥️ Mac (Apple Silicon & Intel)

```bash
# 1. Download EduVault-2.0.0-mac.dmg from Releases
# 2. Open the DMG file
# 3. Drag EduVault to Applications
# 4. Launch from Applications or Spotlight
```

> **Catatan:** Saat pertama buka, klik kanan → Open jika muncul peringatan Gatekeeper.  
> **Note:** On first launch, right-click → Open if Gatekeeper warning appears.

### 🪟 Windows (64-bit)

```
1. Download EduVault-Setup-2.0.0.exe from Releases
2. Run the installer (allow UAC if prompted)
3. Follow the installation wizard
4. Launch from Desktop shortcut or Start Menu
```

### Default Login / Login Default

```
Username: admin
Password: admin123
```

> ⚠️ **Segera ganti password setelah login pertama!** / Change password after first login!

## 🛠️ Development Setup

### Prerequisites

```bash
node >= 18.0.0
npm >= 9.0.0
```

### Clone & Run

```bash
git clone https://github.com/adhithyasoemitro/EduVault.git
cd EduVault
npm install
npm run dev
```

### Build

```bash
# Mac
npm run dist:mac

# Windows
npm run dist:win

# Both
npm run dist:all
```

## 🔐 Security / Keamanan

EduVault dibangun dengan pendekatan security-first:

- ✅ **Password Hashing** — bcrypt dengan salt rounds 12
- ✅ **Context Isolation** — Electron contextIsolation: true
- ✅ **No Remote Code** — Tidak ada remote module, CSP yang ketat
- ✅ **Local-Only Database** — SQLite tersimpan di userData, tidak dikirim ke mana pun
- ✅ **Encrypted Backups** — Backup file dienkripsi
- ✅ **Input Sanitization** — Semua input di-sanitize sebelum masuk DB
- ✅ **Audit Trail** — Semua operasi tercatat dengan timestamp & user

## 🇺🇸 English Version

**EduVault** is a free, open-source school financial management system built specifically for Indonesian schools. It handles:

- **Student Management** with tuition (SPP) tracking
- **Employee Payroll** with automatic tax (PPH 21) and BPJS deductions
- **Complete Accounting** with 7 financial reports
- **Offline-First** with local SQLite database
- **Bilingual UI** (Indonesian ↔ English toggle)
- **Cross-Platform** (macOS + Windows)

Built with Electron, React, TypeScript, and SQLite. MIT Licensed. Free forever.
